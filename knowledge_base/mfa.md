# Multi-Factor Authentication (MFA)

Contoso uses Microsoft Authenticator for MFA on all cloud apps and the VPN.

## New phone
If you still have the old phone, open https://mysignins.contoso.example/security-info and add the new phone before wiping the old one.
If you lost the old phone, raise a ticket — the Service Desk will verify your identity by video call and issue a Temporary Access Pass.

## Not receiving MFA prompts
1. Open the Authenticator app and pull down to refresh.
2. Check notifications are allowed for Authenticator.
3. Use the 6-digit code shown in the app instead of the push prompt.

## Unexpected MFA prompts you did not request
Never approve a prompt you did not start. Deny it and report it immediately — someone may know your password. Then reset your password.
