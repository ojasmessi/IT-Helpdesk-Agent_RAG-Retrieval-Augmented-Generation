# Software Installation and Hardware

## Installing software
Standard users do not have admin rights. Install approved apps from Company Portal (Windows) or Self Service (Mac).
If the app is not listed, raise a software request ticket with the app name, version and business reason. Approval takes up to 3 working days.

## Slow laptop
1. Restart the laptop — many issues clear after a restart (laptops left on for weeks get slow).
2. Install pending Windows updates from Settings > Windows Update.
3. Close browser tabs; check Task Manager for apps using high CPU or memory.
4. If the laptop is older than 4 years it may be due a refresh — raise a hardware ticket.

## Wi-Fi in the office
Connect to "Contoso-Corp" (automatic for managed laptops). Guests use "Contoso-Guest" with the daily password from Reception.

## New starter equipment
Managers request equipment through the New Starter form at least 5 working days before the start date.
